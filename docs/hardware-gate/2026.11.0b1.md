# Hardware gate for 2026.11.0b1

A beta: the release workflow does not require a complete matrix for beta tags, so this records what has been run on real hardware so far. A stable release needs every row in [TEMPLATE.md](TEMPLATE.md) to pass.

Host: an x86-64 mini PC with built-in Wi-Fi, Home Assistant OS 18.4, Home Assistant 2026.11.3; the home network's range contains the camera's.

| camera | driver | arch | detect | list | resume | verify | remux | restore | purge |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| SGK GK720X dashcam (firmware V7_X83_260126) | viidure_app | amd64 | pass | pass | not run | pass | pass | pass | not run |

Notes:

- **Join:** the camera (192.168.0.1) sits inside the home network's range and the address next to it is taken there, so Home Assistant joined point-to-point with a free /32 next to the camera. The default route and DNS stayed on Ethernet.
- **Verify:** the camera's file list gives kilobytes for videos and an unrelated number for photos; downloads were verified against `Content-Length` and `Content-Range` and stored with their real size.
- **Restore:** the camera has no playback mode and keeps recording during a sync; the clip being written is left for the next visit.
- **Resume** and **purge** have automated fault-injection and retention tests but have not been run deliberately on this camera yet.
- Throughput was about 0.6 MB/s at 57 % signal from inside the house.
