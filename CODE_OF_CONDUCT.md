# Code of conduct

Be kind and be useful. This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: treat everyone with respect, assume good faith, give and accept constructive feedback gracefully, and keep discussion on topic. Harassment or discrimination of any kind is not tolerated.

Report problems privately to the maintainer through GitHub (the contact on the maintainer's profile). Reports are handled confidentially.
