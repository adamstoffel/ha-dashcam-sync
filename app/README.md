# Dashcam Sync app repository

Home Assistant app repository for **Dashcam Sync**: pulls clips from Wi-Fi dashcams into Home Assistant, with no phone app.

Add it under **Settings › Apps › App store › Repositories**:
<https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fadamstoffel%2Fha-dashcam-sync>

Then install **Dashcam Sync** and the companion Dashcam Sync integration. Documentation is on the app's *Documentation* tab (`dashcam_sync/DOCS.md`).

Images: `ghcr.io/adamstoffel/dashcam-sync-app-{amd64,aarch64}`, signed with Cosign, SBOM attached.
